# Worn by you, demo photographs

Generate these eight photographs and place them flat inside `C:\fida\FIX` using
the exact file names below. Any common image format is fine. Then run:

```powershell
npm run placeholders
```

The script will resize them, save them into `public/features/`, and refresh the
blur previews automatically.

These are pitch images, not claims about real customers. Replace them with real
customer posts only after receiving permission.

## Shared direction

Use this at the start of every prompt:

> Natural customer-style fashion photograph for a designer ethnic-wear boutique
> in a warm city. Portrait 4:5. An Indian woman wearing the garment comfortably in
> a real social setting, photographed by a friend on a recent phone camera. Soft
> natural light, believable skin and fabric texture, relaxed posture, slight
> everyday imperfections, premium but not staged like a catalogue. The complete
> outfit is easy to see. Warm neutral colour grade with the garment carrying the
> strongest colour. No visible brand names, no text, no watermark, no Instagram
> interface, no shopping bag, no studio backdrop.

Use this negative prompt for every image:

> fashion runway, professional studio, commercial catalogue pose, celebrity,
> influencer ring light, plastic skin, excessive retouching, distorted hands,
> extra fingers, duplicated limbs, warped embroidery, incorrect fabric folds,
> floating jewellery, text, letters, logo, watermark, phone interface, collage,
> frame, border, neon colour, HDR, heavy bokeh, artificial lens flare
